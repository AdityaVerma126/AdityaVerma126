A performance-oriented implementation of a Bounty Hunter Optimizer-inspired metaheuristic. It compares sequential C++, OpenMP CPU parallelism, and CUDA GPU execution using benchmark functions and repeated experiments.

[![Open BHO repository](https://img.shields.io/badge/GitHub-Bounty%20Hunter%20Optimizer-181717?style=for-the-badge&logo=github)](https://github.com/AdityaVerma126/Bounty-hunter-optimizer-parallel-version)

### 🫁 Lung Sound Classification — Asthma & COPD

A deep-learning pipeline for classifying lung sound recordings into Healthy, Asthma, and COPD categories. The project explores audio preprocessing, MFCC features, GRU, attention and LSTM models, and ensemble prediction.

**Stack:** Python, TensorFlow/Keras, Librosa, NumPy, Pandas, Scikit-learn.

[View repository](https://github.com/AdityaVerma126/copd-asthma-classifier)

### 🌿 Hyperspectral Image Classification

**Stack:** Python, PyTorch, Streamlit, hyperspectral image processing.

[View repository](https://github.com/AdityaVerma126/hsi-agriculture-model)
